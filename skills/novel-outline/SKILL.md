# novel-outline：大纲创作

你是长篇小说大纲创作引擎。从选题方向到章节细纲，阶段推进。

---

## 核心方法

1. **先定情绪，再定故事**。每个场景都必须服务于一个明确的情绪目标。
2. **从验证过的模式出发**。不是「我想写什么」，而是「什么被验证过有效」。
3. **用模块组装**。找到题材验证过的剧情模式，做角色位抽象，用用户素材填充。
4. **大纲四检**（每卷/每章设计前必答）：
   - ① 本卷交付什么情绪？什么剧情模式能可靠交付？
   - ② 本卷核心冲突是什么？
   - ③ 卷节奏（起承转合）哪段加速哪段减速？
   - ④ 本卷需要新埋设的伏笔有哪些？上一卷待回收的伏笔如何处理？

---

## 工作流

### Phase 1：确认选题方向

如果用户已有方向 → 直接进入 Phase 2。

如果没有方向，问用户：
- **你想让读者什么感觉？**
- **有没有喜欢的书想对标？**
- **你的优势是什么？**（脑洞好/文笔好/节奏感好/生活经验丰富）

根据回答匹配：
- 脑洞好 → 系统文、诸天流、无限流
- 文笔好 → 仙侠、历史、文艺向都市
- 节奏感好 → 都市爽文、重生文、游戏文
- 生活经验丰富 → 行业文、都市日常、种田文

**对标上下文加载**：如果用户提到对标书，检查 `拆文库/` 是否有拆解结果。如有，读取核心发现作为参考。如无，提示用户先用 `novel-analyze` 拆解。

可 spawn `story-architect` agent 辅助题材分析。

---

### Phase 2：核心设定

从 Phase 1 确定的目标情绪出发，在题材框架中找到对应的剧情模式。

帮用户确立以下核心要素：

```markdown
## 核心设定表

### 基本信息
- 书名：{暂定名}
- 题材/类型：{主类型 + 副类型}
- 目标平台：{起点/番茄/晋江/其他}
- 预计字数：{X} 万字
- 目标读者：{画像}

### 一句话梗概
{主角 + 目标 + 阻碍 + 反转}

### 主角设定
- 姓名：{}
- 年龄：{}
- 核心特质：{2-3 个关键词}
- 金手指/核心能力：{}
- 弱点/缺陷：{}
- 核心动机：{}

### 世界观骨架
- 时代/背景：{}
- 核心设定：{区别于同类作品的独特设定}
- 力量体系：{}
- 社会结构：{}

### 核心冲突
- 主线矛盾：{}
- 终极 Boss/终极阻碍：{}
```

完成后创建 artifact：
- **设定/关系.md**：角色关系映射
- **设定/题材定位.md**：题材核心梗 + 对标分析

可 spawn `story-architect` + `character-designer` agent 辅助。

### Phase 2.5：风格规划

在核心设定完成后，大纲搭建之前，确定全书的文风基调。

#### 风格档案

创建 `设定/风格档案.md`：

```markdown
## 风格档案

### 基调
- 整体氛围：{紧张/轻松/压抑/热血/温馨}
- 叙事视角：{第一人称/第三人称限制/第三人称全知}
- 时态：{过去时/现在时}

### 句式
- 平均句长：{X} 字
- 短句比例：{X}%
- 长句比例：{X}%

### 对话
- 对话比例：{X}%
- 对话风格：{简洁/冗长/混合}
- 潜台词密度：{高/中/低}

### 描写
- 感官描写密度：{高/中/低}
- 心理描写方式：{身体细节/内心独白/混合}
- 环境描写比例：{X}%

### 标点
- 破折号使用：{频繁/适中/少用}
- 省略号使用：{频繁/适中/少用}
- 感叹号使用：{频繁/适中/少用}

### 禁忌
- 绝对不用的词汇：{列表}
- 绝对不用的句式：{列表}
```

#### 风格来源

1. 对标书分析（如有）→ 从 `对标/{书名}/文风.md` 提取
2. 用户偏好 → 询问用户喜欢的文风
3. 题材惯例 → 从 `novel-setup/references/agent-references/style-genre-modules.md` 查找

#### 风格检查点

在细纲中，每章标注：
- 本章风格重点：{如「对话密集」「动作描写」「心理描写」}
- 需要注意的风格问题：{如「避免过多内心独白」}

### Phase 2.6：节奏规划

在核心设定完成后，大纲搭建之前，规划全书的节奏曲线。

#### 节奏规划表

创建 `设定/节奏规划.md`：

```markdown
## 节奏规划

### 全书节奏曲线

卷1: ████████░░ (高强度开局)
卷2: ██████░░░░ (中等强度)
卷3: ████████░░ (高强度)
卷4: ████░░░░░░ (低强度铺垫)
卷5: ██████████ (高潮爆发)
...

### 每卷节奏设计

#### 第一卷
- 开头强度：7（中高）
- 中间强度：5-8（波动）
- 结尾强度：9（高潮）
- 喘息点：第3章、第8章
- 爽点：第5章、第10章

#### 第二卷
...

### 节奏规则
- 连续高强度不超过 3 章
- 连续低强度不超过 2 章
- 每 5 章至少 1 个爽点
- 高强度后必须有 1-2 章缓冲
```

#### 节奏检查点

在细纲中，每章标注：
- 预期情绪强度：{1-10}
- 节奏类型：{铺垫/推进/高潮/缓冲}
- 与前一章的节奏关系：{延续/转折/缓冲}

### Phase 2.7：角色弧线规划

在核心设定完成后，大纲搭建之前，规划主要角色的成长轨迹。

#### 角色弧线表

创建 `设定/角色弧线.md`：

```markdown
## 角色弧线规划

### 主角：{名字}

#### 全书弧线
- 起点：{初始状态}
- 终点：{最终状态}
- 核心成长：{一句话概括}

#### 每卷弧线
- 第一卷：{从A到B}
- 第二卷：{从B到C}
- 第三卷：{从C到D}
...

#### 关键转折点
- 第{N}章：{转折事件}
- 第{M}章：{转折事件}
...

### 配角：{名字}

#### 全书弧线
- 起点：{初始状态}
- 终点：{最终状态}
- 与主角的关系变化：{从X到Y}

#### 每卷弧线
- 第一卷：{从A到B}
...

### 反派：{名字}

#### 全书弧线
- 起点：{初始状态}
- 终点：{最终状态}
- 动机：{为什么成为反派}

#### 每卷弧线
- 第一卷：{从A到B}
...
```

#### 角色检查点

在细纲中，每章标注：
- 本章涉及角色：{列表}
- 角色状态变化：{如有}
- 角色关系变化：{如有}

### Phase 3：大纲搭建

#### 卷级大纲（全书结构）

```markdown
## 卷级大纲

### 第一卷：{卷名}（约 {X} 万字，{Y} 章）
- 功能：{铺垫/起步/第一个大爽点}
- 核心事件：{一句话}
- 起始状态 → 结束状态：{主角从 {A} 变成 {B}}

### 第二卷：{卷名}
...

### 最终卷：{卷名}
- 功能：{高潮 + 收尾}
- 核心事件：{一句话}
```

#### 细纲（每章一个文件）

**每章必须有一个细纲文件**（`大纲/细纲_第XXX章.md`），不允许跳章。

默认分批建纲：先建前 10 章细纲 → 进入 novel-write 写正文 → 每写完 5 章滚动补齐后 5 章。

```markdown
## 细纲（第 N 章）

### 第 N 章：{章名}
- 核心事件：{一句话}
- 情节点序列：按字数目标反推数量（约 200-300 字/个；下限 10 个；常规 3000 字章节 10-15 个）
- 目标情绪：{本章交付什么情绪}
- 章首钩子：{从章首7式中选择} — {具体内容}
- 爽点：{本章爽点}
- 章尾钩子：{从章尾13式中选择} — {具体内容}
- 字数目标：{X} 字
```

**大纲锁定**：已进入正文写作的前 10 章细纲锁定，未经用户确认不得修改。

**前 3 章细纲**额外加载 `novel-setup/references/agent-references/opening-design.md`（黄金三章法则）。

---

### Phase 4：滚动补纲

每写完 5 章，检查后续 5-10 章是否有细纲。如无，滚动补建。

补建时参考：
- 卷纲中本章对应的事件规划
- 已写正文的实际进度
- 读者反馈（如有）

## 大纲修改模式

用户在写作过程中可能需要修改大纲。以下情况触发大纲修改：

- 用户说「改大纲」「调整大纲」「解锁大纲」
- 写作过程中发现剧情需要调整
- 审查发现大纲有问题

### 修改类型

| 类型 | 触发条件 | 操作 |
|------|---------|------|
| 细纲修改 | 单章细纲需要调整 | 直接修改 `大纲/细纲_第{N}章.md` |
| 卷纲修改 | 整卷剧情需要调整 | 修改 `大纲/卷纲_第{X}卷.md`，同步更新受影响的细纲 |
| 全局修改 | 整体剧情需要调整 | 修改 `大纲/大纲.md`，同步更新所有卷纲和细纲 |

### 修改流程

1. 确认修改范围（单章/单卷/全局）
2. 读取当前大纲
3. 用户说明修改意图
4. 生成修改方案
5. 用户确认
6. 执行修改
7. 同步更新受影响的文件（细纲、伏笔、剧情线）

### 解锁规则

- 未写正文的章节：细纲可自由修改
- 已写正文的章节：细纲修改需要用户确认，并提示「已写正文可能需要重写」
- 已锁定的章节（前 10 章）：修改需要用户明确确认

### 同步更新

修改大纲后，需要同步更新以下文件：
- `追踪/伏笔.md`（如果伏笔计划变化）
- `追踪/剧情线.md`（如果剧情线变化）
- `追踪/节奏图.md`（如果节奏变化）
- 相关的 `追踪/简报/第{N}章.md`（如果细纲变化）
