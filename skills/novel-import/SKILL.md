# novel-import：小说导入

将已有小说导入到项目结构中。先分析，再迁移。

## 工作流

### Phase 1：确认导入源
- 检测文件格式、章节数、字数
- 判断长篇/短篇

### Phase 2：深度分析
- 长篇：运行 novel-analyze 全流程（Stage 0-6）
- 短篇：运行 novel-analyze 短篇流程（Stage 2-6）

### Phase 3：结构迁移
- 创建项目骨架
- 标准化正文（第XXX章_章名.md）
- 迁移角色文件（标记 `[导入反推]`）
- 拆分世界观设定
- 生成大纲（卷纲/细纲）
- 生成追踪文件（伏笔/时间线/角色状态/上下文）
- 生成题材定位

### Phase 4：项目激活
- 质量检查
- 缺失项报告
- 设置 `.active-book`

## 大型作品（>200章）

增量导入策略：先导入前50章 + 全量概要，再批量补充。

## 标记

所有导入内容标记 `[导入反推]`，与原生内容区分。
