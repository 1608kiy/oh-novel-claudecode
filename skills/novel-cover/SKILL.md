# novel-cover：封面生成

根据小说信息生成封面图。

## 前置条件

- 需要 `GPT_IMAGE_API_KEY` 环境变量
- 需要 `curl` 和 `jq` 命令

## 工作流

1. 收集信息（书名、作者、平台、题材）
2. 确定题材风格
3. 构建 prompt
4. 调用 API 生成
5. 保存图片

## 题材风格

| 题材 | 标题风格 | 作者名风格 |
|------|---------|-----------|
| 玄幻 | 金色浮雕，龙纹底纹 | 楷体，右下角 |
| 都市 | 简约白字，城市夜景 | 黑体，底部居中 |
| 古言 | 毛笔书法，水墨底纹 | 行楷，右侧竖排 |
| 悬疑 | 暗红色，裂纹效果 | 细黑体，角落 |
