# Novel Format Rules

正文文件的格式规范。

## Rules

1. **段落长度**：单段不超过 60 字。超过时按句号/动作转折拆开。

2. **句子长度**：单句不超过 45 字。超过时拆成两句。

3. **对话格式**：对话独立成段，不与叙述混在一起。

4. **禁止空行**：正文段落之间不留空行（段落本身就是一个镜头）。

5. **章节标题格式**：`# 第{N}章 {章名}`

6. **文件命名格式**：`第{N}章_{章名}.md`（章节号3位补零：001, 002, ...）

7. **禁止情绪词**：不直接写"心痛""愤怒""恐惧"等情绪词，用身体细节替代。

8. **对话标签**：尽量少用"他说""她说道"等标签，用动作或上下文区分说话人。

9. **信息密度**：前 100 字至少包含 3 个事件。

10. **爽点密度**：每 3000-5000 字至少有一个让读者「爽」的节点。

## Examples

### Correct — 身体细节替代情绪词
```
❌ 他感到非常愤怒。
✅ 他手背上的青筋一根根暴起来。

❌ 她心里很难过。
✅ 她咬着下嘴唇，咬出一道白印，松开后迅速红了。
```

### Correct — 对话独立成段
```
"你为什么要这么做？"沈昭问。

周文远没有回答。他转过身去，看着窗外的月亮。

"因为我知道得太多了。"他说。
```

### Wrong — 对话与叙述混在一起
```
❌ "你为什么要这么做？"沈昭问，周文远没有回答，他转过身去，看着窗外的月亮，"因为我知道得太多了。"他说。
```
